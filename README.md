# 🔐 CyberChef PGP

## 📌 Sobre o projeto

Laboratório prático realizado durante o programa *Mulheres Digital, utilizando o **CyberChef* para compreender, na prática, o funcionamento da criptografia assimétrica com PGP (Pretty Good Privacy).

## 🎯 Objetivo

Demonstrar a geração de um par de chaves PGP, a criptografia de uma mensagem utilizando a chave pública e a posterior descriptografia da mensagem utilizando a chave privada correspondente.

## 🛠️ Ferramentas utilizadas

- CyberChef
- PGP (Pretty Good Privacy)

## 🔑 Conceito aplicado

A criptografia assimétrica utiliza um par de chaves:

- *Chave pública:* utilizada para criptografar a mensagem.
- Chave privada: utilizada para descriptografar a mensagem.

A chave privada deve ser mantida em segurança e nunca deve ser compartilhada publicamente.

## 🧪 Etapas realizadas

### 1. Geração das chaves

Foi utilizado o recurso *Generate PGP Key Pair* do CyberChef para gerar:

- Chave pública
- Chave privada

### 2. Criptografia da mensagem

Foi utilizada a operação *PGP Encrypt*.

A mensagem foi inserida no campo de entrada e a chave pública foi utilizada para realizar a criptografia.

### 3. Armazenamento

O resultado criptografado foi armazenado em um bloco de notas para utilização na etapa seguinte.

### 4. Descriptografia

Foi utilizada a operação *PGP Decrypt*.

A mensagem criptografada foi inserida no campo de entrada e a chave privada correspondente foi utilizada para recuperar a mensagem original.

### 5. Validação

Após a descriptografia, a mensagem original foi recuperada com sucesso, demonstrando o funcionamento do processo de criptografia assimétrica.

## 💬 Mensagem utilizada

> Primeira atividade concluída no Mulheres Digital! Esta mensagem foi criptografada e posteriormente descriptografada com sucesso utilizando chaves PGP no CyberChef.

## 📚 Aprendizados

A atividade permitiu compreender, de forma prática:

- O funcionamento da criptografia assimétrica;
- A diferença entre chave pública e chave privada;
- O processo de criptografia e descriptografia utilizando PGP;
- A importância da proteção da chave privada;
- A utilização do CyberChef como ferramenta para análise e experimentação em segurança da informação.

## 🔎 Resultado

A mensagem foi criptografada utilizando a chave pública e posteriormente descriptografada utilizando a chave privada correspondente, recuperando corretamente o conteúdo original.
